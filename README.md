# SnapSort – AI-Powered Smart Event Media Organizer

## Overview
SnapSort is a web-based application that helps photographers and event organizers manage large collections of event photos and videos. It uses AI-based face detection and recognition to group media featuring the same person, making it easier for attendees to find their photos.

## Problem Statement
After large events, photographers may have thousands of photos and videos. Manually sorting them and sharing individual photos with attendees takes significant time and effort.

SnapSort aims to automate this process through AI-powered media organization and search.

## Key Features
- Bulk upload of event photos and videos
- AI-based face detection and person-wise grouping
- Search for photos using a selfie
- Event-based media galleries
- Video timestamp identification
- Duplicate media detection
- Secure media storage and access

## Technology Stack
- **Frontend:** React.js, Vite
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **AI Service:** Python, FastAPI, computer vision
- **Object Storage:** MinIO
- **Version Control:** Git and GitHub

## Project Structure
- `frontend/` – User interface
- `backend/` – API and application logic
- `ai-service/` – Face detection and AI processing
- `docs/` – Project documentation
